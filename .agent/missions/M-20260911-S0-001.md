# Mission M-20260911-S0-001

## Goal
Prove that the proposed AI Agent Platform can accept a real software mission, dispatch it to a local coding agent, execute against a real GitHub repository, validate the result, repair failures, and produce acceptance evidence.

## Target Repository
`stanleyshen7916-creator/Project-Development-Platform`

## Scope
1. OpenHands Agent Canvas local runtime.
2. Claude Code via ACP.
3. Shared Mission Bus state in `.agent/`.
4. Real repository workspace access.
5. One harmless real repository task.
6. Test/build/runtime evidence.
7. Failure → repair → retest demonstration.

## Constraints
- No direct AI API integration is required for the POC.
- Prefer local subscription authentication for Claude Code.
- Do not expose secrets in the repository.
- Do not mount the Docker socket into n8n as a shortcut.
- Do not merge changes into `main` automatically during the POC.

## Definition of Done
The mission is complete only when all requirements in `PROJECT_STATE.md` are PASS and evidence exists for the complete execution chain.

## Acceptance Evidence
- Local Agent Canvas URL or runtime proof.
- Claude Code ACP authentication proof without exposing credentials.
- Repository inspection evidence.
- Real change in the target repository.
- Test/build result.
- Runtime verification result where applicable.
- At least one induced/reproducible failure followed by agent repair and retest.
- Final acceptance report.
